# 法典图鉴 · ComfyUI 节点

把 **NovelAI 提示词法典**接进 ComfyUI：节点上开一个**非模态窗口**，窗口正面就是线上站点
（[novelai.quicktagcloud.com](https://novelai.quicktagcloud.com/)）本身 —— 站点的全部功能都在里面：
浏览例图、搜索筛选、NAI↔SD 语法切换、Tag 中转站、灯箱、站点自己的收藏。

插件只在这之上补三样东西：**把词条推送到节点**、**自己的一份收藏**、**打开你的图库**。

> 改造说明：这版把原先内嵌的「本地离线站点」整个去掉了 —— 那一套要跟着仓库分发 45 MB 词库、
> 还要另外下 1.4 GB 例图。现在窗口直连线上站点，插件目录里只剩图库那一页。
> **代价是需要联网。**

## 快速上手

1. **装**：把整个 `ComfyUI-m8tags` 文件夹放进 `<ComfyUI>/custom_nodes/`，重启 ComfyUI。
2. **连**：加一个 `法典图鉴 · 文本编码`，把它的 `clip` 接上 checkpoint 加载器的 CLIP，
   它的 `positive` / `negative` 两个输出分别接 KSampler 的 `positive` / `negative`。
   这个节点本身就等于一个「CLIP文本编码」，**不用再串一个**。
3. **逛**：点节点上的 `前往词典站寻找灵感` 开窗口，在右边站点里挑。
4. **取**：在卡片上点 `全部`（或 `负面`）复制 → 回到窗口点 `＋ 从剪贴板取词` → 点 `推送到节点`。

想省掉第 4 步的手点，见下面「运行前自动换词」。

## 窗口里有什么

```
┌──────────────────────────────────────────────────────────────┐
│ ◆ 法典图鉴   [搜词条…] [搜索] [我的图库] [浏览器打开] [关闭]  │
├──────────────────────────────────┬───────────────────────────┤
│                                  │ ＋从剪贴板取词 －取负面 ★收藏│
│                                  ├───────────────────────────┤
│   线上站点（iframe）             │ 已选栏                    │
│   浏览 / 搜索 / NAI↔SD /         │ POSITIVE（转换·字数）      │
│   中转站 / 收藏 / 灯箱           │ NEGATIVE                  │
│                                  │ [清空] [推送到节点]        │
└──────────────────────────────────┴───────────────────────────┘
```

顶栏那几个按钮：`搜索` 是把关键词送进站点自己的搜索（带 `?q=` 跳过去），
`我的图库` 把右侧换成图库页，`浏览器打开` 在独立标签页里打开线上站点。

## 推送到节点：为什么要点两下

站点在 iframe 里，而它是**另一个域名**。浏览器对跨域 iframe 的隔离是硬的：
父页面读不到它的 URL、读不到它的 DOM，而站点本身也没有留任何跨窗口通信接口
（没有 `postMessage`、没有 `BroadcastChannel`、没有暴露全局对象 —— 这几条都实测过）。

所以「你在网页里选了哪一条」插件无从得知，中间必须过一次**剪贴板**：

1. 在站点卡片上点 `全部`（复制正向 + 角色词）或 `负面`（复制负向）
2. 回到右侧栏点 `＋ 从剪贴板取词` 或 `－ 取负面`

内容会**原样**进正/负预览框，插件不替你猜格式 —— 站点自己就有 SD 权重开关，
你在站点里开着 SD 模式复制，拿到的就是 SD 语法；没开就是 NAI 语法。
想就地转一次，点预览框边上的 `转成 A1111`。

合并规则：按逗号拆开、忽略大小写去重。站点复制「正向 + 角色词」时是用换行分段的，
插件会先把换行折成逗号。

## 收藏

两种东西都能收，都带分类：

- **词条文本** —— 取词之后点 `★ 收藏`，下次点 `载入` 直接进已选栏
- **网页位置** —— 点 `存当前网页位置`，把窗口现在这一页（法典 + 路径 + 搜索词）存下来，
  下次点 `打开` 窗口直接跳过去

存在浏览器里（ComfyUI 这个源的 localStorage，键名 `qtc-m8-favs`）。
站点自己那套收藏在它自己的域名下 —— 那是站点的事，两边互不干扰。

## 我的图库

窗口顶栏点 `我的图库` 就切过去（插件自己伺服的 `atlas/gallery.html`）。
把图拖进去，自动读出底模、LoRA、提示词，**只给 C 站链接不下载**。
图片存在 `<插件目录>/atlas/self-image/`，索引是同目录的 `index.js`。

这一页跟线上站点没关系，断网也能用。

## 随机抽词

节点上的 `随机提示词` 从**线上那份数据**里抽 —— 插件按需取，用完就扔，不落盘：

```
data-source.json  →  current.json（当前发布号）
                  →  releases/<发布号>/codexes.json（法典清单）
                  →  releases/<发布号>/<法典id>.json（用到哪部才拉哪部）
```

一个进程里只留内存缓存；站点一发新版（发布号变了），缓存整个作废重取。

- `法典来源` 下拉决定从哪部抽。选 `全部法典（不含 R18）` 时**不会抽画师词典**里的词条
  —— 那种词典通篇是画师 tag，一条就能把整张图的画风带偏。想抽就明确选中那一部。
- 抽到的是 NAI 原文，切 `语法` 就地转成 A1111（纯前端转换，不重新联网），
  转换时权重为负的那批会挪进负向框。

### 运行前自动换词

点节点上的 `运行自动随机：关（点击开启）`。开着的时候，每次运行工作流都会在提交前重新抽一条
—— `Run` 按钮、`Ctrl+Enter`、只跑选中的输出节点、队列空时的自动续跑全算。

抽完立刻写进框里，**提交上去的就是你看到的那一份**。开关是每个节点各自一份，
存在节点的 `properties.codexAtlasAutoRandom` 里，跟着工作流走。

抽词接口报错（没网、取不到数据）时只弹一条提示，**不会拦住运行**。

## 节点与设置

| 入口 | 输出 | 什么时候用 |
| --- | --- | --- |
| `法典图鉴 · 文本编码` | `CONDITIONING` ×2 | **推荐**，自带 `clip` 输入，直接接 KSampler |
| `法典图鉴 · 提示词` | `STRING` ×2 | 只想产出文字，或者把文本转给别的节点 |
| 内置 `CLIP文本编码` 上的按钮 | 无（改造原节点） | 工作流里已经堆了一堆 CLIPTextEncode |

第三个是设置项：`设置` → 搜「法典图鉴」→ 打开
**「法典图鉴：在「CLIP文本编码」节点上显示按钮」**（默认关，改完刷新页面生效）。

节点上的控件：`前往词典站寻找灵感` / `随机提示词` / `运行自动随机` / `语法切换` / `法典来源` / `negative`。

## 接口

| 方法 | 路径 | 干什么 |
| --- | --- | --- |
| GET | `/codex_atlas/codexes` | 法典清单（取线上，带缓存） |
| GET | `/codex_atlas/random?codex=<id>` | 随机抽一条，返回 NAI 原文与负向 |
| GET | `/codex_atlas/status` | 后端身份与可用功能 |
| GET | `/codex_atlas/atlas/{tail}` | 图库页静态文件 |
| POST | `/codex_atlas/self-image` | 存图（base64） |
| POST | `/codex_atlas/self-image/delete` | 删图（不可逆，会记流水） |
| POST | `/codex_atlas/self-image/group` | 改分组 |

## 测试

```
node   tests/test_convert.mjs     # 语法转换回归
node   tests/test_auto_random.mjs # 前端行为：开关、只抽开着的那几个、收藏存取
python -m unittest discover -s tests -p "test_*.py"
```

下面两个要真浏览器（用 `CHROME` 环境变量指过去，不指就用本机装的 Playwright chromium）：

```
node tests/verify-gallery.mjs     # 图库独立页能不能用（不需要联网）
node tests/verify-window.mjs      # 真开一次窗口：iframe 加载、图库切换、收藏板、关窗（要联网）
```

`test_auto_random.mjs` 不起浏览器：把模块里那行裸 import 换成注入的假 `app`，
照 ComfyUI 的顺序真跑一遍（`setup()` → `nodeCreated()` → 点按钮 → `queuePrompt()`），
断言的是行为而不是文本 —— 纯文本断言（"文件里有某函数名"）测不出少写一次 `await` 这类问题。

`test_routes.py` 里的在线取数用例不发真请求：`_http_json` 整个换成假的，四跳链条每跳单独验。

`verify-window.mjs` 起一个假后端（假的 `/scripts/app.js` + 真的 `codex_atlas.js` 与 `atlas/`），
然后在真浏览器里开一次窗口。这条验的是交付物本身 —— "某个按钮根本没挂上"这种问题，
读代码看不出来。它就是这么抓到一个真 bug 的：预览框的 input 回调闭包抓了参数 `node`，
而窗口是公开调试入口、不传 node 也能开，于是 `renderPicks` 一渲染就抛异常。

## 已知边界

- **需要联网**：窗口正面是线上站点，随机抽词也要取线上数据。图库那一页不用。
- **跨域隔离**：插件读不到站点内部状态（这是浏览器的规定，不是没做），
  所以推送必须过一次剪贴板。
- **API 提交不触发自动随机**：那条钩子挂在浏览器前端的运行入口上。
  用脚本直接 POST `/prompt` 提交工作流时不会换词，跑的是框里最后一次的内容。
- 站点改版可能让默认参数（`c` / `p`）失效 —— 那几个参数是站点自己的路由，
  失效了换一下默认法典即可，其它功能不受影响。
